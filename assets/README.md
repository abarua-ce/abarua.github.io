# assets/

Drop these two files here to complete the site:

- **`portrait.jpg`** — a square headshot (e.g. 600×600). If it's missing, the
  site shows a purple "AB" monogram automatically, so this is optional.
- **`cv.pdf`** — your CV/résumé. The hero "Download CV" button links to it.

Filenames must match exactly (lowercase).
